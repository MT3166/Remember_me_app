# 0.2.0 绿色声音画室

## 设计与实现

用户选择原话：`B  但是配色可以改成绿色`。方向已记录在 `design-demos/direction-approved.md`。

- B 版首页采用浅叶绿背景和深绿录音按钮，保留暖色状态提示。
- 将单页编辑表单拆为记录、确认、阅读三步。竖屏内容可滚动，主要按钮固定在底部；横屏阅读时正文与封面并排。
- 语音识别成功后自动进入校准确认；文字输入也可校准。录音波形来自识别服务实际 RMS 回调，未启用录音时不伪造声音数据。
- 校准确认保存选定正文并保留原始转写，正文成功写入本机后才生成封面。失败可重试或只保存文字。
- 增加明确的朗读停止状态，长日记分段朗读；页面切换和进入后台时停止语音操作。
- 草稿、待确认日记、已保存日记分别恢复到记录、确认、阅读页。各阶段可通过更多菜单删除日记。
- 家长设置保留接口与密钥配置，保存按钮也固定于底部。

## 验证结果

- `assembleDebug`、`testDebugUnitTest`、`assembleDebugAndroidTest`、`lintDebug` 全部通过。
- 9 项 JUnit 测试通过，包括地址与响应文本规则、页面恢复、采纳校准版本、封面过期、长朗读分段与 Unicode 保留。
- 20 项安卓端侧检查通过，包括两种文字协议、异常响应、本地存储、旧写入防回退、Keystore 加密与篡改检测，以及 ViewModel 校准保存和迟到录音隔离。
- 0.1.0 覆盖安装到 0.2.0 成功，原有 `sample-park.json` 保留且可读。
- UI 验证通过：待确认结果进入确认页；保存校准正文与原文；强制结束进程后恢复阅读；拒绝麦克风权限后仍可文字输入；缺少文字或生图密钥时不丢正文；编辑与删除；家长入口与设置保存。
- 截图检查：1600x2560 平板竖屏、2560x1600 平板横屏、800x1600 窄屏、1.3 倍字体、实际软键盘显示。主要操作按钮可访问，文字未发现重叠。
- 模拟器 UI 测试关闭系统动画以稳定输入法截图，并兼容首次与重复拒绝权限的不同按钮。没有因此更改 APP 的键盘布局逻辑。
- Lint 为 0 错误、6 条非阻断警告、1 条提示。已有依赖升级和旧版备份配置提示未扩展改动。
- 绿色 HTML 原型也通过 Playwright 操作及竖屏、横屏、窄屏检查。
