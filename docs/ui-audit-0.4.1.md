# 0.4.1 界面检查（2026-09-08）

结论：基础布局与绿色方向可用，语音状态和横屏空间分配仍需修正，暂不建议视为儿童独立使用体验已验收。

范围：专用 Android 模拟器，1600×2560 竖屏、2560×1600 横屏；实际查看首页、阅读、确认、语音待机、文字编辑与键盘、文本/图片/语音配置。示例日记和图片来自既有测试素材，不是真实生图结果。未连接荣耀真机或调用收费接口。

## 问题与建议

1. **P2：失败重试入口与按钮名称不一致（代码确认）。**
   DiaryUi.kt:303 展示重试入口，但底部空正文分支仍显示“开始说”（322），圆形麦克风仍标识“开始录音”，状态仍是“准备好了”（349）。SpeechController.kt:50 遇到该日记有待重试录音时直接上传旧文件，不开始新录音。孩子以为重新录音会漏掉新说的话。应将此状态明确显示为“上次没识别成功”，主要按钮为“重试”，另设“重新录音”。本轮未向真实接口制造失败，结论来自调用路径核对。

2. **P2：识别中仍提示继续说，计时仍走（代码确认）。**
   DiaryUi.kt:332、338 使用 active（录音或识别中）控制计时与“想到哪里，就说到哪里”。此时 MediaRecorder 已停止；标题虽然正确显示正在转文字，副标题和计时却产生冲突。建议录音结束冻结时长，识别中提示“说完啦，等我记下来”。

3. **P2：横屏录音首屏状态被截断（截图确认）。**
   artifacts/audit-041-voice-landscape.png：固定间距和纵向排列使“准备好了”在滚动区域底边被切断，已有转写文字位于首屏外。可滚动找回，因此不是永久遮挡。DiaryUi.kt:279、330 应按可用高度压缩间距，或横屏采用录音控件与转写内容分栏；录音/处理状态保持可见。

4. **P2：横屏键盘下编辑区过小（截图确认）。**
   artifacts/audit-041-keyboard-landscape.png：输入框标签部分裁切，固定底部两个操作占据较大空间。正文仍能输入，不属于完全不能编辑。DiaryUi.kt:116、294 可在键盘展开时缩成单行操作栏，降低非编辑内容高度，优先保证正文可视区域。实际荣耀输入法高度还需真机核验。

## 通过项与次要建议

- 首页横屏分栏、竖屏单栏；阅读页封面和正文、确认页主要操作均可访问。
- 模型配置三标签可切换，文本页实际显示 MiniMax-M3，保存按钮可见。
- 按钮尺寸、正文对比度和绿色配色方向合适。
- 竖屏短日记留白较多、封面重绘仅用刷新图标，属于后续视觉和可发现性优化，优先级低于上述问题。
- 模拟器冷启动阶段首张截图落在启动页，已重拍；初次阅读横屏截图早于页面切换，也已重拍，不作为应用故障证据。

本轮为检查与问题记录，未修改应用实现或生成新版本。
