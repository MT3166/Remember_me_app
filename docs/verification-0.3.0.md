# 0.3.0 模型供应商配置

## 行为

- 入口：家长设置 → 配置供应商。
- 独立文本与图片标签页，两边均支持 OpenAI（GPT）和 MiniMax 国内。
- 官方 URL 与默认模型内置，常规配置只需填写 API Key；模型名称可在高级设置修改。
- 每种用途分别记住每家供应商的模型和 Key，切换时不把旧供应商 Key 带给新供应商。
- 同一官方供应商可开启图片共用文本 Key；切换到不同供应商时关闭共用。
- 图片接口已实现 OpenAI GPT Image 请求与响应解析，保留 MiniMax 原生图片协议。图片测试直接生成测试图，不需要文本模型 Key。
- 自定义 URL、OpenAI / Anthropic 文本协议、GPT Image / MiniMax 图片协议仍可使用。
- 旧版已保存的官方配置自动识别；其他地址和 Anthropic 配置归入自定义，保留 Key、模型和协议。
- 所有供应商配置继续保存在原 Keystore 加密文件中。未保存草稿保存在 ViewModel，旋转屏幕保留；按返回放弃。

默认模型与接口依据见 [官方文档记录](provider-api-sources.md)。
