# 第一版验证记录

日期：2026-09-07。版本：0.1.0（debug 家庭试用包）。

## 已通过

- APK 编译与安装：Android SDK 36，Build Tools 36.1.0，Gradle 8.14.3，JDK 21。
- 5 项 JUnit 测试：接口地址规则、拒绝不安全地址、思考内容过滤、正文修改后的封面过期判断。
- 16 项 Android 端侧检查：两种协议请求与解析、截断及业务错误、非法校准结构、日记读写、版本防回退、删除后迟到写入、路径校验、密钥加密读写与篡改检测。

- UI 操作：缺少模型密钥时保留正文；保存后强制结束进程，再打开能恢复；家长算式入口可用。
- 页面检查：1600x2560 平板竖屏、2560x1600 平板横屏、800x1600 窄屏；截图非空且文字无重叠。
- 最后调整封面预览最大宽度至 420dp，平板竖屏可直接看见两个保存按钮；重新构建与检查通过。
