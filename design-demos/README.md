# 小小日记：三方向交互初稿

本轮使用用户指定的 huashu-design（输入为 huash-desgin，对应本机已安装技能），完成方向选择前的真实视觉与交互原型。

后续选择已确认：用户选择 **B，改为绿色**。绿色原型为 [声音画室绿色版](studio-green.html)，已经落实到原生安卓 0.2.0；原三版保留用于对照。

## 打开预览

- [A：故事画廊](gallery.html)：清楚的日期和封面网格，突出回忆与查找。
- [B：声音画室](studio.html)：录音入口优先，按说、听、收组织操作。推荐作为 5 岁孩子的起点。
- [C：我的小书页](book.html)：书页式阅读与柔和排版，强调亲子翻阅。

每个文件自包含图片、字体、图标和脚本，直接打开即可，无需安装依赖或启动服务器。默认展示四个可独立操作的主要屏幕；右上角的“单屏体验”使用整个浏览器窗口，可旋转设备查看横竖屏。

这三版是选型原型，不是新 APK。录音与模型结果使用演示数据，不实际请求麦克风或模型。浏览器朗读仅在点击后尝试系统中文声音；没有可用声音时提示失败。演示设置只影响当前预览，不填写真实密钥。

## 验证

使用本机已有 Playwright 和 Chromium，无新增前端包。

- 三方向均通过详情进入、录音开始结束、原文展开、正文修改与空文本限制、保存及封面等待状态、家长设置操作。
- 四个主要状态分别验证 800x1280 竖屏、1280x800 横屏、390x844 窄屏，共 36 个布局组合。
- 图片全部加载，主要底部按钮未超出屏幕，页面没有水平溢出，控制台与 pageerror 均为零。
- 已人工检查三版总览与代表性的竖屏、横屏、窄屏截图，修正书脊文字排布与图标尺寸。
- 自动结果见 `verification.json`；截图位于 `screenshots/`。

## 继续开发

用户选择原话已记录到 `direction-approved.md`。B 的绿色版本已实现到 Kotlin Compose APP，保留本地存储、模型协议与语音能力，完成 APK 与模拟器验收；后续在荣耀平板验证真实模型和语音。

实现源文件为 `prototype.js`、`prototype.css`、三个方向 CSS 和 `prototype-template.html`。`node build-prototypes.cjs` 生成三个独立 HTML。`verify-prototypes.cjs` 使用当前机器已有的 Playwright 绝对路径，在其他机器运行时需调整该路径。

需求详见 `design-spec.md`，素材版权与参照记录见 `asset-sources.md`。
