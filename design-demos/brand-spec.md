# 品牌与素材约定

- 项目名称：小小日记，来自现有 APP 与已交付 APK。
- 目标人群：5 岁孩子及协助设置、确认的家长；以用户原话为事实依据。
- 目标平台：安卓平板，当前目标设备荣耀 V8 Pro。原型仅使用内容画布，不复制 Pixel 或 iPhone 硬件外形。
- 现有识别元素：应用中的书本图标与“小小日记”名称；本轮用 Lucide book-open 保留语义，其他操作也使用同一图标库。
- 三方向共享素材：绘画、绿叶、早餐三张演示照片。图片为日记封面的视觉样例，不冒充用户孩子或 AI 实际生成结果。
- A：从现有绿色延伸到清晰画廊布局，增加日期层级和红色细线标记。
- B：取绘画主题的黄色与红色，辅以绿色确认状态，强化孩子可以直接识别的动作区域。
- C：柔和玫瑰色与叶绿色，用手写感标题和书脊组织亲子阅读。
- 字体：正文 Noto Sans SC，标题在 C 中使用 LXGW WenKai TC；均内嵌授权字体子集。
- 禁止把方向初稿当作用户已批准的最终设计；没有新的方向选择原话，不能建立 direction-approved.md。
- 不引入真实密钥或新的云服务，不把设计原型的模拟状态当作生产能力验证。
- 用户最终选择 B 并要求绿色：主要动作 `#286C49`，录音入口 `#D8EDB7`，背景 `#FBFCF8`，暖黄和珊瑚色仅作辅助提示；原生实现沿用 Material 图标库。
